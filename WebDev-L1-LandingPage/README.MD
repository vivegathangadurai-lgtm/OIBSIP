# Kaarigar — Every Hand, Verified (Landing Page)

A modern, responsive landing page for a trade network platform matching verified tradespeople with customers. Built as part of the **Oasis Infobyte Virtual Internship Program (OIBSIP)**.

## 🚀 Features
- **Responsive Layout:** Adaptive design using CSS Grid & Flexbox across desktop, tablet, and mobile screens.
- **Accessibility Enhanced:** Standard contrast ratios, semantic HTML structure, and screen-reader accessible mobile navigation toggle (`aria-expanded`).
- **Interactive UI:** Custom CSS components including a dynamic job ticket card and verified stamp styling.
- **Smooth Navigation:** In-page anchor scrolling with sticky header.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Custom Properties, Flexbox, CSS Grid)
- **JavaScript** (Vanilla JS for mobile nav toggle)
