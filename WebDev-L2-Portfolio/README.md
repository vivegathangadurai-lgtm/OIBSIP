# Personal Portfolio Website (Task 2)

A modern, responsive personal developer portfolio showcasing technical skills, featured projects, and contact avenues built for the **Oasis Infobyte Internship Program (OIBSIP)**.

## 🚀 Features
- **Modern Dark UI:** Clean layout using custom CSS properties and responsive cards.
- **Interactive Navigation:** Sticky header with backdrop blur and smooth in-page scrolling.
- **Projects Showcase:** Highlighted cards featuring project descriptions, tech tags, and source links.
- **Responsive Layout:** CSS Grid and Flexbox ensuring adaptation across desktop, tablet, and mobile displays.
- **Interactive Form:** Functional front-end contact section.

## 🛠 Tech Stack
- **HTML5** (Semantic Structure)
- **CSS3** (Variables, Flexbox, CSS Grid, Transitions)
- **JavaScript** (Interactivity)
